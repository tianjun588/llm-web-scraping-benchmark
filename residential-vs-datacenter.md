# Residential vs Datacenter Proxies for RAG Pipelines

When building LLM RAG (Retrieval-Augmented Generation) knowledge bases, data freshness is paramount.

* **Datacenter Proxies**: Fastest latency and lowest cost, but blocked on >60% of modern web domains.
* **Residential Proxies**: Sourced from real domestic ISPs. Ideal for bypass rates exceeding 99%.
